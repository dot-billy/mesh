# Apple platform goal completion audit

Last updated: 2026-07-25.

This audit maps the Apple platform integration goal to authoritative evidence.
It is not a support statement and it does not promote source, simulator, or
local feasibility evidence into release evidence. The canonical per-product
gate inventory remains
[`../packaging/apple/release-verification-matrix.json`](../packaging/apple/release-verification-matrix.json);
that matrix keeps every product `unsupported` and `release_eligible` false.

The evidence states used here are:

- **Implemented**: the reviewed source boundary exists and its source tests
  pass.
- **Locally proved**: a bounded receipt exists from this development Mac or a
  disposable checkout on it.
- **Externally proved**: the required independent host, physical device,
  distribution channel, or native CI produced the bounded evidence.
- **Blocked**: a required authority decision, external environment, physical
  device, protected release action, or coordinated rollout is absent.

No **implemented** or **locally proved** entry satisfies a gate that explicitly
requires protected release, clean-host, native-host, physical-device,
distribution, control-plane, or packet-path proof.

## Overall completion criteria

| Completion criterion | Status |
| --- | --- |
| Supported, packaged, signed, notarized, documented, and independently verified macOS Admin | **Not complete** — bounded local protected evidence exists, but approval, publication, clean-host, native workflow, update, and uninstall evidence do not. |
| Supported authenticated macOS Node with clean-host packet and lifecycle proof on supported architectures | **Not complete** — production policy is unapproved and production enrollment remains disabled. |
| iOS Admin simulator and physical auth, RBAC, custody, accessibility, and mutation proof | **Not complete** — simulator/source proof exists; no physical-device or installed distribution evidence exists. |
| iOS Tunnel real-device tunnel, roaming, suspension, rotation, revocation, and distribution proof if support is declared | **Not complete** — source proof and one earlier qualification upload exist; support is not declared and physical evidence is absent. |
| Every distributed artifact bound to source, release metadata, signing, and independently verifiable provenance | **Not complete** — local receipts exist, but no final approved publication set exists. |
| No Apple path exposes a node private key to the control plane, Flutter, logs, or ordinary storage | **Implemented and source-tested** — physical custody and removal evidence is still required. |
| Linux and Windows source, package, API, storage, backup, and packet gates remain green | **Not complete** — exact-Go Linux container runs passed the corrected `mesh-install`, `mesh-release`, and all non-host-kernel `linuxinstall` tests. An isolated current-source snapshot cross-compiles every root-module Windows test package and package for both `amd64` and `arm64`. Workflow source now declares native Ubuntu and Windows test/build jobs triggered by every Go change. Docker Desktop cannot prove systemd/cgroup, anonymous-file, or native packets; cross-compilation does not execute Windows tests; package, storage, backup, and packet matrices remain outstanding; and no current external native CI run exists. |
| Public/API documentation describes only proved behavior and explicit limitations | **Passing for the current unsupported source state** — final supported-product handoff remains blocked on the missing evidence above. |

The Apple platform goal is therefore **not complete**. The next irreversible or
externally consequential actions are intentionally gated:

1. approve or revise ADR 0011 before any production macOS Node policy is
   embedded;
2. provide fresh action-time authorization before signing, notarizing, or
   uploading new Apple bytes;
3. coordinate the persistent control-plane rollout before changing its schema
   or routes;
4. attach or install on physical iPhone/iPad hardware for the Admin and Tunnel
   matrices;
5. run and retain evidence from the declared independent clean Apple, native
   Linux, native Windows, and supported Intel macOS environments for their
   non-substitutable gates.
